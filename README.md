# RevitBatchNWCExport

Плагин для Revit 2022–2027, который пакетно экспортирует модели в NWC. Кнопка «NWC Экспорт» находится на вкладке «roshior-a», панель «Экспорт».

## Как работает

1. При запуске плагин загружает по HTTP дерево моделей всех серверов из `C:\ProgramData\Autodesk\Revit Server <год>\Config\RSN.ini`. Это тот же список серверов, что Revit показывает в окне открытия. Пока дерево грузится, показывается окно прогресса.
2. В окне экспорта есть две вкладки: «Revit Server» и «Папка с файлами». Экспортируются модели, отмеченные на активной вкладке.
3. Каждая модель открывается отсоединённой от хранилища. NWC экспортируется с 3D-вида, имя которого содержит заданный текст (или совпадает с ним точно). После экспорта модель закрывается без сохранения. Если подходящих видов несколько, берётся первый по алфавиту.

Настройки окна хранятся в `%AppData%\RevitBatchNWCExport\settings.json`.

> **Скорость загрузки дерева.** Сейчас плагин при каждом запуске обращается к серверам напрямую, поэтому загрузка может занимать время. Если серверы долго загружаются, рекомендуется хранить текстовый кэш адресов моделей в доступном месте, периодически его обновлять и читать его в коде плагина вместо прямых запросов к серверам.

Для работы нужен установленный Navisworks NWC Export Utility для своей версии Revit.

## Сборка

Для каждой версии Revit своя конфигурация: `Debug R22` … `Release R27`.

| Revit     | .NET            |
|-----------|-----------------|
| 2022–2024 | .NET Framework 4.8 |
| 2025–2026 | .NET 8          |
| 2027      | .NET 10         |

```bash
dotnet build src/RevitBatchNWCExport/RevitBatchNWCExport.csproj -c "Release R22"
```

- **Release** собирает готовую папку `dist/Revit<год>/`.
- **Debug** после сборки сам устанавливает плагин в `%AppData%\Autodesk\Revit\Addins\<год>\`. Revit при этом должен быть закрыт.
